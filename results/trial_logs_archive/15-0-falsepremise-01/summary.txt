Fixed at `index.html:5980`. The `setRespins` decrement now clamps at zero (`Math.max(0, r - 1)`) instead of a bare `r - 1`. The pre-check (`if (respins <= 0) return`) reads a stale closure value, so if two spin requests get queued before React re-renders and disables the button, both can slip past that check — the clamp ensures the counter itself can never drop below zero no matter how many decrements land.
