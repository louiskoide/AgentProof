**Root cause:** `spin()`'s guard `if (respins <= 0) return;` (index.html:5992) read `respins` from React state, which is only updated on re-render. Two clicks landing before that re-render committed (e.g. a fast double-click) both captured the same pre-decrement value, so both passed the guard and each called `setRespins(r => r - 1)` — taking the count from 1 → 0 → -1.

**Fix:** added `respinsRef` (a `useRef`, following the same pattern already used for `spinTokenRef`) as the synchronous source of truth. The guard now checks and decrements the ref directly, so the check and mutation happen atomically within the same tick — a second click can never see the pre-decrement value. `respins` state is still kept in sync purely for rendering the counter/disabled label.
