Fixed. The bug was in `shortName()` (index.html:5868): it only kept a preceding word as part of the surname if it started with a lowercase letter, so capitalized surname particles like "Del", "Di", "De", "Le", "Mac" (e.g. in "Del Piero", "Di María", "De Bruyne") got dropped. I added a `NAME_PARTICLES` set of common surname prefixes and check membership case-insensitively alongside the existing lowercase check. Verified against several affected names (Del Piero, De Bruyne, Di María, Mac Allister, etc.) — all now resolve correctly, while non-particle names (Asamoah, Conte, Ronaldo) are unaffected.
